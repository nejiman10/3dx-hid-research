# Report `0x17` と98%・100%表示の限定比較

2026-09-27、利用者は同じマウスのBluetooth経由の電池表示が日本時間9時12分ごろに98%であり、Receiverへ切り替える直前にも変わらなかったと報告した。USBケーブル接続前にReceiver経由の入力を20秒間、読み取り専用で取得した。表示値は利用者申告であり、この監査は表示画面そのものを保存していない。

| 条件 | 結果 |
| --- | --- |
| 取得時間 | 00:14:31.162586～00:14:51.162914 UTC（9時14分31秒～51秒 JST） |
| 対象 | C652 MI_03、入力descriptor SHA-256 `8e31d4b6f8e0c5eb5ff01617d202f8f29421f514fd05a187a2ca3c777aea9efc` |

| 設定・結合状態の書き込み | なし |

`0x62` は十進98で、約2分半前のBluetooth表示98%と一致する。同一個体・近接時刻での一致を示す限定観測であり、この1点だけでbyte 1が常に百分率であるとは確定できない。byte 2の `0x00` も、非充電条件との相関観測にとどまり正式意味は未確定。Receiverへ切り替えた後のBluetooth表示の同時確認はできていない。

利用者は、PCにつながっていない充電ケーブルを日本時間9時17分ごろ接続したと報告した。接続後、同じC652 MI_03入力nodeから9時18分38秒～58秒 JSTの20秒間に646 raw frameを取得し、そのうちReport `0x17` は3件すべて `17 64 01` だった。設定・結合状態の書き込みは行っていない。ケーブル接続とReport変化は観測したが、充電電流や同時刻の独立した電池残量表示は確認していない。byte 1の `0x62→0x64` が実残量の変化か、給電状態に依存する表示かは判定できない。byte 2の `0x00→0x01` もケーブル接続と相関する範囲にとどまる。

利用者は充電ケーブルを外し、日本時間9時20分ごろにBluetooth表示が100%になったことを確認してから、USBケーブルを接続せずReceiverへ戻した。9時22分09秒～29秒 JSTに同じC652 MI_03入力nodeを20秒間取得し、1179 raw frame中のReport `0x17` 2件はいずれも `17 64 00` だった。Bluetooth表示の画面そのものは保存しておらず、切り替え後の同時表示もない。
